# Resultados do estudo

O índice principal está em [`tables/analysis_index_final.csv`](tables/analysis_index_final.csv). Os caminhos locais das linhas são relativos à raiz do repositório.

- [`tables/`](tables/): tabelas consolidadas e dicionário de unidades.
- [`benchmark/`](benchmark/): 3.936 resultados de seis algoritmos.
- [`isa/`](isa/): quatro modelos com SIFTED corrigido.
- [`stn/`](stn/): 190 trajetórias decimais e redes derivadas.
- [`generation/`](generation/): mapas históricos de geração, curvas e finalistas.
- [`figures/`](figures/): visualizações finais.
- [`audit/`](audit/): registros de verificações e metadados.

Leia a [interpretação dos resultados](../docs/resultados.md) antes de combinar tabelas. Execute `python3 scripts/verify_repository.py` para conferir a integridade desta edição.
